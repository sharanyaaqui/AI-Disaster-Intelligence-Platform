
# AI Disaster Intelligence Platform

## Overview
AI Disaster Intelligence Platform is a web-based disaster management system that enables citizens to report disasters, upload images, receive alerts, and provides an interface for AI-based disaster prediction.

## Technologies Used
- Python
- Flask
- SQLAlchemy
- SQLite
- Flask-CORS
- Werkzeug

## Features
- User Registration
- User Login
- Disaster Report Submission
- Image Upload
- Report Verification
- Alerts API
- Dashboard API
- AI Prediction Endpoint (Placeholder)

## Installation

```bash
git clone <repository-url>
cd AI-Disaster-Intelligence-Platform
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Server runs on:

http://127.0.0.1:5000
